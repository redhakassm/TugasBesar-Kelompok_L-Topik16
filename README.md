# TugasBesar-Kelompok_L-Topik16.
Aplikasi OoTeWe.in mengombinasikan Multi Linked List untuk mengelola relasi many-to-many Penyelenggara dan Destinasi lewat node penawaran (jadwal, biaya, kuota), serta Binary Search Tree (BST) untuk mencatat pendaftaran peserta berbasis ID agar pencarian dan validasi dapat dilakukan dengan cepat.
